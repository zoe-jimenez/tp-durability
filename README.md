# TP 2 et 3 : Le poids caché du web
 
Page web de départ pour les TP 2 (CSS) et 3 (JavaScript) du module de développement web, OC informatique.
 
## Contenu
 
- `index.html` : la page « Le poids caché du web », version corrigée du TP 1
- `style.css` : la feuille de style, à compléter
- `datacenter.svg` : l'illustration de la page
## Utilisation
 
1. Cliquez sur **Use this template**, puis **Create a new repository**, pour créer votre propre copie (dépôt public, sur votre compte).
2. Déposez le lien de votre dépôt en commentaire du ticket prévu dans l'onglet **Issues**.
3. En classe, clonez votre dépôt dans VS Code et enregistrez votre travail par des commits réguliers.
